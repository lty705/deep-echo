# 深窟回声 · Deep Echo

手机触屏动作 Roguelike —— 纯前端 Canvas 小游戏，无需后端、无构建步骤。

## 运行方式
- 直接用浏览器打开 `index.html` 即可游玩；
- 或部署到任意静态托管（GitHub Pages / CloudBase / CloudStudio 等）。

## 操作
- **触屏**：左半屏拖动 = 移动，右半屏点击 = 攻击，右半屏滑动 = 闪避（闪避瞬间精准顶招触发完美闪避）
- **桌面**：WASD 移动，J 攻击，K 闪避

## 特性
- **4 种职业**（数据驱动，手感迥异）：坚壁守卫（坦克）/ 疾风游侠（敏捷）/ 余烬咒师（远程火球）/ 影刃（近战·快攻吸血）
- **无名遗物**探索机制：遗物不写说明，靠实战推断，首次推断自动入图鉴
- **古老祭坛**三选一抉择（风险 vs 收益）
- 打击特效（挥砍弧光 / 命中冲击环 / 火花 / 顿帧震屏 / 子弹拖尾）
- 玻璃拟态 UI、明/暗/系统主题切换、独立敌人剪影

## 目录结构
```
index.html        入口与各类覆盖层（菜单 / 选角 / 祭坛 / 图鉴 / 强化 / 死亡）
src/
  config.js      全局配置 + 职业 CLASSES 数据
  meta.js        元进度持久化（localStorage）
  input.js       触屏 / 键盘输入
  world.js       关卡生成（房间 / 墙 / 祭坛 / Boss）
  entities.js    玩家 / 敌人 / 子弹 / 粒子 / 特效
  relics.js      遗物与职业签名叠加
  game.js        状态机 / 渲染 / HUD / 覆盖层流程
src/style.css    玻璃拟态样式与主题
```
